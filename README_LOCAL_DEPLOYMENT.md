# DOST Region V CSF - Local Deployment & Google Apps Script Setup Guide

This guide explains how to deploy and run the **DOST Region V Customer Satisfaction Feedback (CSF)** WebApplication locally on any machine while retaining full integration with **Google Apps Script** (for auto-filling Google Docs templates).

---

## 🚀 Quick Start (One-Click Local Deployment)

### Option 1: Double-Click Launcher (Windows)
1. Double-click **`start-local.bat`** in the project folder.
2. The launcher script will automatically:
   - Verify Node.js runtime.
   - Test internet connectivity to `script.google.com` (Google Apps Script).
   - Read or prompt for your `GOOGLE_WEBHOOK_URL`.
   - Start the local webserver on `http://localhost:3000`.
   - Automatically open `http://localhost:3000/admin.html` in your default web browser.

### Option 2: Command Line / Terminal
1. Open Command Prompt or PowerShell in this directory.
2. Run:
   ```bash
   npm start
   ```
3. Open `http://localhost:3000/admin.html` in your browser.

---

## 🔗 Connecting with Google Apps Script (Google Docs Auto-Filler)

1. Deploy your Google Apps Script Web App (see instructions in `GOOGLE_APPS_SCRIPT.md`).
2. Open the Admin Console: `http://localhost:3000/admin.html`.
3. Click **DB Settings** (in the top right navigation bar).
4. Paste your **Google Webhook URL** (e.g. `https://script.google.com/macros/s/.../exec`).
5. Select **Dual Mode** (Saves to local SQLite database AND syncs with Google Docs).
6. Click **Save Configuration**.

---

## 📊 Summary Report Sign-Off Setup

In `http://localhost:3000/admin.html` -> **DB Settings**:
You can set custom names and positions for summary reports:
- **Report Generated By**: Name & Position (e.g., `Dr. Maria Santos`, `QMS Quality Assurance Officer`)
- **Report Approved By**: Name & Position (e.g., `Engr. Ernesto M. Granada`, `Regional Director`)

These sign-off details will automatically populate when you click **Print Summary Report**.

---

## 💾 Local Database File

- Local SQLite Database: `data/csf_database.sqlite` (Uses Node.js standard library `node:sqlite`).
- Backup JSON File: `data/responses.json`.
